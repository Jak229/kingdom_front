# Линия фронта

Браузерная игра в духе Kingdom: сайд-скроллер про командира гарнизона «Перевал». Днём строишь базу и нанимаешь бойцов, ночью держишь линию против боевых роботов.

**Играть:** https://jak229.github.io/kingdom_front/

- Движок Phaser 3.80.1 (лежит в `vendor/`), всё остальное — обычные JS-модули без сборки. Игре не нужен интернет: Phaser, шрифты и спрайты — локальные файлы.
- Управление: ←/→ или A/D, Shift — бег, ↓/S (удерживать) — заплатить монету, Esc/P — меню, M — звук. На телефоне — экранные кнопки.
- 6 языков: ru, en, uk, es, de, zh.
- Правила и устройство игры: [DESIGN.md](DESIGN.md).

Запуск локально: любой статический сервер, например `python3 -m http.server`, затем открыть http://localhost:8000. Двойной клик по `index.html` не сработает: браузер не грузит модули с `file://`.

Версия: v20.

## Сборка для игровых порталов

```
cd export
npm install
npm run build
```

Получится `export/front-line-v20.zip` (и та же папка распакованной в `export/dist/`). В архиве `index.html` лежит в корне, все пути относительные, модули собраны в один скрипт `js/game.js`, внешних запросов нет. Такой zip загружается на порталы, принимающие HTML5-игры (itch.io, CrazyGames, Poki, GameDistribution, Яндекс Игры и т.п.), и работает внутри их iframe. SDK порталов пока не подключены.

Что уже сделано под требования порталов: название без чужой торговой марки, в iframe игра не включает полноэкранный режим сама, забирает фокус клавиатуры по клику, отпускает зажатые кнопки при потере фокуса, стрелки и пробел не прокручивают страницу портала, нет меню браузера по правому клику и долгому нажатию, звук выключается в скрытой вкладке. Как и исходники, сборку нужно открывать через веб-сервер, а не двойным кликом по файлу.

## Как устроен код

В игре нет звуковых файлов, а единственная картинка — атлас спрайтов `assets/sprites.png`, который тоже нарисован кодом.

**Спрайты.** Каждый спрайт — маленькая функция, которая «красит» прямоугольники на сетке, например `P.r(2,6,24,18,C.con)` — прямоугольник 24×18 цветом бетона. `pxSprite()` в `art/core.js` выполняет эту функцию на холсте, затем проходит по пикселям: добавляет блик сверху, тень снизу, лёгкое зерно, снег зимой и тонкий контур. Палитра — `PAL` в том же файле.

Игра сама спрайты не рисует: она загружает готовый атлас `assets/sprites.png` (все кадры на одной картинке) и `assets/sprites.json` (где какой кадр лежит, размеры и точки привязки). Если поменяли рисунок в `art/`, пересоберите атлас:

```
cd art
npm install
npm run build
```

Сборщик `art/build.mjs` открывает `art/build.html` в Chromium (через Playwright), рисует все спрайты и записывает PNG и JSON в `assets/`. Готовый атлас лежит в репозитории, так что для игры и для GitHub Pages ничего собирать не нужно.

**Звук.** `js/audio.js` строит всё через Web Audio API: осцилляторы (синус, пила, квадрат) и короткие буферы шума, пропущенные через фильтры и огибающие громкости. Выстрел — щелчок шума с быстрым затуханием, мотор — пилообразная волна с пульсацией «вспышек» и фильтром, музыка — пошаговый секвенсор, который играет аккорды, бас, флейту и барабаны по нотам. Логика игры только просит звук через `sfx(вид, x)`, а аудио решает, как он звучит и с какой стороны.

### Файлы

```
index.html              разметка: меню, настройки, экранные кнопки
css/style.css           оформление меню и интерфейса поверх игры
css/fonts.css           подключение локальных шрифтов из fonts/
fonts/                  Pixelify Sans и Rubik (woff2, лицензия SIL OFL)
vendor/phaser.min.js    движок Phaser 3.80.1 (лицензия MIT)
export/                 сборка zip для игровых порталов
js/main.js              точка входа: язык, тип управления, запуск Phaser
js/config.js            размеры мира, сезоны, таблицы построек, машин, лавок
js/state.js             состояние игры S, ввод, новая партия
js/settings.js          настройки игрока в localStorage
js/save.js              сохранение на рассвете и загрузка
js/util.js              мелкие математические помощники
js/i18n/                тексты: index.js (tr(), выбор языка) и файл на каждый язык
js/logic/               правила игры без рисования
  rules.js              стройка, оплата, ракета, фланги, стрельба
  tutorial.js           обучение в первый день
  people.js             бродяги, солдаты, строители, фермеры
  enemies.js            ночи, волны, все роботы и боссы
  defences.js           турели, снайпер, миномёт
  support.js            ПТУР, спецназ, финотдел, конвой, машины, пёс
  step.js               один такт симуляции всего мира
js/sprites.js           загрузка атласа спрайтов и их размеры
js/render/              помощники рисования и фоновые слои параллакса
js/scene.js             сцена Phaser: каждый кадр вызывает step() и рисует мир
js/audio.js             синтез звуков и музыки
js/ui/                  меню, настройки, экранные кнопки, панель обучения, экран победы
assets/sprites.png      атлас спрайтов (собирается из art/)
assets/sprites.json     координаты кадров в атласе
art/                    исходники спрайтов: core.js — движок рисования, остальные — рисунки,
                        index.js — список всех спрайтов, build.mjs — сборщик атласа
```
